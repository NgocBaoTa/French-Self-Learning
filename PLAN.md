# Kế hoạch triển khai

## Đã làm — Phase 1

1. Tạo cấu trúc `frontend/`, `backend/`, `docs/`.
2. Tạo schema SQLite và seed idempotent.
3. Tạo API auth, dashboard, vocabulary, review và quiz.
4. Tạo UI responsive tiếng Việt cho luồng học chính.
5. Viết test backend cho auth, cô lập user, grading và review persistence.
6. Ghi hướng dẫn Windows, backup/restore và trạng thái giới hạn.

## Phase 2 kế tiếp

- Flashcard hai chiều, thuật toán review có due/weak cards và mistake review.
- Goals và progress chart có dữ liệu thật.

## Phase 3 kế tiếp

- Admin source library, local PDF upload, Google Drive public-file validation, page rendering/OCR review.
